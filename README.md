# Chocolate Sales Analysis — Power BI

## Project Overview
An interactive Power BI project designed to analyze chocolate sales data and identify sales trends, product performance, and geographic insights using MySQL as the data source.

## Tools & Technologies
- **Power BI Desktop** — Dashboard creation and visualization
- **MySQL** — Data storage and querying
- **SQL** — Data preparation and analysis

## Dataset
The project uses the Awesome Chocolates dataset, containing:
- `sales`
- `products`
- `people`
- `geo`

## Project Files
- `Chocolate_Sales_Analysis_Report.pbix` — Power BI report
- `awesome-chocolates-data.sql` — SQL dataset script (if included)

## How to Use
1. Import the SQL dataset into MySQL.
2. Connect Power BI to the `chocolate_analysis_db` database.
3. Open the `.pbix` report in Power BI Desktop.
4. Refresh the data if prompted and explore the dashboard.
